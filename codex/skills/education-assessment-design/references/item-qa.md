# Item QA record

Use one record per scored item and pin its revision. This template records a review result; it does not replace the item or its verified solution.

| Field | Entry |
| --- | --- |
| Item and blueprint | `item_id@revision`, `blueprint_id@revision` |
| Construct and objectives | Objective IDs, requirement IDs, intended cognitive demand |
| Prompt and format | Exact learner-facing wording and response mode |
| Key check | Independent solution method, answer, units and alternate valid answers |
| Scoring check | Maximum points, partial credit, point total and rubric consistency |
| Fairness and access | Language load, accommodation effect on construct, ambiguity and clues |
| Source and permission | Source anchor or original-item declaration, copyright permission where relevant |
| Variant check | Seed, answer mapping and equivalence evidence when varied |
| Result | pass, revise or block, reviewer, date and retest scope |

For a calculation, solve from the prompt without consulting the drafted key and compare the result. For a constructed response, try a defensible alternative that the rubric should accept. For a selected-response item, inspect every distractor for a plausible misconception and check that no option is made conspicuous by grammar or length. A `pass` requires the recorded checks to be performed; unverified fields remain open.
