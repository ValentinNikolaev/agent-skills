# Version and review controls

Use one ephemeral working record rather than repeatedly rebuilding the brief. Retain it across a long-task checkpoint when needed, excluding private source dumps and council transcripts.

Record:

- source packet identity/revision, complete relevant content or accessible evidence references, coverage and freshness limits;
- speaker, recipient, placement, contribution, voice constraints, required translations and deliverable count;
- exact draft text or an unambiguous version/hash for each option and translation;
- required gates with `pending`, `passed`, `failed`, or `unavailable`, the checked version, and evidence;
- baseline draft, substantive repair count, remaining budget, and unresolved objections.

A hash identifies a version; it does not prove a check ran. Record actual assessment or service output separately. A later stage may reuse the source packet only after confirming every reviewer still has the same complete content. Restore missing context before judging; a summary alone is not equivalent to a previously required full source.

## Invalidate only the affected work

| Change | Revisit |
| --- | --- |
| New source clarification, changed recipient, purpose, or interpretation | Source/intent decision and affected drafts and assessments |
| Changed reasoning, stance, structure, or substantive wording | Local edit checks and required exact-copy assessment for that option |
| Typo or meaning-preserving punctuation | Coordinator comparison; preserve unchanged editorial judgments when policy permits |
| Any change to text submitted to a required exact-text service | Service evidence for the new submitted text, even if editorial judgments remain valid |
| Another option changes | That option; keep unrelated valid assessments |

When independent reviewers are required, record their individual findings before sharing anonymized responses for peer challenge. Reuse the initial reviewers for revised versions within the host budget. Returning reviewers are not blind new readers; disclose their prior exposure and keep earlier scores out of fresh packets. Agreement is not factual verification or proof of the author's preference.

Keep interpretation, editorial quality, service observations, and any requested engagement or future-post assessment separate. An undefined rubric yields an unresolved numeric assessment, not an invented number. Follow the owner's explicit qualitative fallback when available.
