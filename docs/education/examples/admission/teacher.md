# Chiave e criteri per il docente

Conservare queste risposte separatamente dal foglio dello studente. Registrare se la risposta è stata data con aiuto. Un solo tentativo e un tempo breve descrivono questa prova, senza consentire una previsione di ammissione.

**item-1.** x = 2 oppure x = 3. (x − 2)(x − 3) = 0. Il prodotto nullo esaurisce i due casi. Un punto per entrambe le radici e un punto per un metodo completo, inclusa la formula risolutiva corretta.

**item-2.** (−4, 0) e (3, 0). f(x) = (x + 4)(x − 3); sull’asse x l’ordinata è zero. Un punto per le ascisse corrette, uno per le coordinate complete con la motivazione. Accetta l’ordine inverso.
