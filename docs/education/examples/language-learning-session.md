# Language learning session sample

This is an original synthetic Italian task with English learner instructions. No CEFR level or official curriculum alignment is asserted. The learner has asked to practise making a polite request in a café. The task tests communicative success and grammatical form separately. A live tutor should ask for one response at a time and record the learner's actual answer before continuing. Read the model, then cover it before attempting the three tasks. Every spoken line also appears in text, so audio is optional.

## Goal and model

LANG-O1 asks the learner to request one drink politely in Italian and respond to a clarification. Model exchange.

> Cliente: Buongiorno, vorrei un tè, per favore.
>
> Barista: Caldo o freddo?
>
> Cliente: Caldo, grazie.

The expression `vorrei` makes the request polite. `Caldo o freddo?` asks the learner to choose hot or cold. The English prompt explains the task, while the requested response remains in Italian. Translation is support for comprehension and does not replace production in the target language.

## Initial task

Prompt LANG-I1. “You are in a café. Ask for a coffee politely in Italian. Then answer if the barista asks `Con latte?`” Write both turns before asking for feedback.

## Reformulated and delayed retrieval

After a correction, try LANG-I2 in a new setting. “At a bakery, ask for water politely. The server asks `Naturale o frizzante?` Choose still water.” At a later study opportunity, try LANG-I3 without the model visible. “Ask politely for tea and choose it cold.” Ask for feedback after completing each exchange. A future review date is a plan only if scheduling is actually available.
