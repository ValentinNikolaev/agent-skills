# Матеріали для вчителя

Для швидкої діагностики окремо попросіть назвати довжину маршруту та кінцеву координату. Нуль замість шляху може означати змішування понять або неправильно прочитану умову. Попросіть описати кожну ділянку до пояснення правила. Повторіть перевірку на іншому маршруті після перерви.

**item-1.** Шлях 13 м, Δx = +3 м. 8 + |3 − 8| = 13; 3 − 0 = +3. По одному балу за кожну величину з одиницею та правильним напрямком для Δx.

**item-2.** 12 м. 18 м / 6 с = 3 м/с. За 4 с шлях 3 × 4 = 12 м. Варіант 3 плутає швидкість із відстанню. Один бал за відповідь, один за обґрунтування з одиницями.

**item-3.** Нульовим є переміщення, бо кінцева та початкова координати збігаються. Під час прогулянки довжина маршруту додатна. Один бал за назву величини, один за пояснення через координати.
