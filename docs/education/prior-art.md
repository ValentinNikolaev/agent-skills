# Education skill prior art

Inspected on 2026-11-25. The six repositories below are independent projects. Their source files were read with `gh api` at the listed commits. File inspection establishes what each repository contains, while claims of educational effectiveness would require learner outcome evidence that this inspection did not provide. No external text, scripts, schemas, or examples were imported into this MIT repository.
